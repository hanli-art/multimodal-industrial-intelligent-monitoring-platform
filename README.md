# 多模态工业智能监控平台

面向工业厂区安全生产的智能监控系统：在 AI 识别核心（YOLOv8m 目标检测 + 通义千问 VL 场景安全分析）之上，实现实时监控、AI 告警、违规取证、设备管理、数据总览、统计报表、权限管控、系统配置与操作留痕全流程闭环。

版本：**v1.0**（R0 ~ R11 迭代完成）

## 一、技术栈

| 层次 | 选型 |
|---|---|
| 后端 | FastAPI + Uvicorn，端口 `8200` |
| 数据库 | MySQL（PyMySQL 驱动，原生 SQL，不引入 ORM） |
| 前端 | 原生 HTML / CSS / JavaScript，图表用 ECharts（CDN 引入） |
| 实时通道 | WebSocket（检测、大模型分析、告警广播三通道） |
| 视频源 | 本地视频文件 / PC 摄像头（不做 RTSP 与硬件对接） |
| AI 能力 | YOLOv8m 目标检测 + 通义千问 VL 大模型场景安全分析 |

## 二、功能模块

| 模块 | 说明 | 对应页面 |
|---|---|---|
| 实时监控 | 本地视频 / 摄像头取流抽帧，YOLO 画框 + 千问违规分析 | `index.html` |
| AI 告警管理 | 违规自动入库、防抖、筛选分页、处理与误报驳回 | `alarms.html` |
| 实时告警推送 | WebSocket 广播 + 右下角弹窗 + 语音播报 + 顶部告警条 | 全站（`js/notify.js`） |
| 违规取证溯源 | 违规帧自动抓拍落盘、按条件检索、图片下载 | `alarms.html` 内嵌预览 |
| 设备管理 | 设备台账增删改查、按车间分组、心跳模拟在线状态 | `devices.html` |
| 数据总览 | 数据卡片 + 违规占比 / 告警趋势 / 车间排名图表 | `dashboard.html` |
| 统计报表 | 日 / 周 / 月台账，支持导出 CSV（UTF-8 BOM） | `reports.html` |
| 权限与人员 | 登录验证码、三级角色、接口二次校验 | `login.html` |
| 系统配置 | 算法开关、逐类违规启停、置信度阈值、告警防抖 | `settings.html` |
| 操作日志 | 关键操作全程留痕，按时间 / 用户 / 类型检索 | `logs.html` |

## 三、部署步骤

### 1. 环境准备

安装 Python 3.10+ 与 MySQL 5.7+，然后创建虚拟环境并安装依赖：

```bash
python -m venv venv
venv\Scripts\activate              # Windows
# source venv/bin/activate         # macOS / Linux

pip install -r requirements.txt
```

### 2. 获取 YOLO 模型权重

把 `yolov8m.pt` 放到项目根目录（该文件不入库）：

```bash
pip install ultralytics
yolo predict model=yolov8m.pt      # 自动下载权重到当前目录
```

也可从 [Ultralytics 官网](https://docs.ultralytics.com/models/yolov8/) 手动下载后拷贝到项目根目录。

### 3. 配置环境变量

复制 `.env.example` 为 `.env`，按实际环境填写（`.env` 不入库）：

```ini
# 阿里云百炼（DashScope）API Key，用于千问 VL 场景安全分析
DASHSCOPE_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
# 千问模型名，需与百炼控制台已开通的模型一致
QWEN_MODEL=qwen3.8-omni-flash

# MySQL 连接信息
DB_HOST=127.0.0.1
DB_PORT=3306
DB_USER=root
DB_PASSWORD=你的数据库密码
DB_NAME=industrial_monitor
```

> 未配置 `DASHSCOPE_API_KEY` 时服务仍可正常启动，但 `/ws/qwen` 无法调用大模型，也就不会产生新的违规告警。

### 4. 初始化数据库

```bash
python init_db.py
```

脚本会自动建库、建表（devices / alarms / evidences / users / op_logs / config 共 6 张表）、创建种子账号与 3 台模拟设备。脚本可重复执行：已存在的结构与数据不会被破坏。

### 5. 启动服务

```bash
python server.py
```

服务监听 `0.0.0.0:8200`，浏览器访问 <http://localhost:8200>，未登录会自动跳转到登录页。

## 四、账号说明

系统内置三种角色（种子账号首次初始化时写入，密码以「盐 + SHA256」存储）：

| 账号 | 密码 | 角色 | 可用范围 |
|---|---|---|---|
| `admin` | `admin123` | 超级管理员 | 全部功能（含设备管理、系统配置、操作日志） |
| `safety` | `safety123` | 安全管理员 | 实时监控、告警处理、取证查看、数据总览、统计报表；无设备管理 / 系统配置 / 操作日志 |
| `viewer` | `viewer123` | 查看员 | 实时监控、告警列表、数据总览（只读）；不可处理告警、不可导出报表、不可进入管理类页面 |

权限为「前端菜单显隐 + 后端接口二次校验」双重控制：前端按角色隐藏入口，后端对越权请求返回 `403`，未登录访问 `/api/*` 返回 `401`。

> 生产使用前请登录后修改默认密码，并妥善保管 `.env` 中的 API Key。

## 六、操作手册

### 6.1 登录与登出

1. 打开 <http://localhost:8200>，页面自动跳转到登录页。
2. 输入账号、密码与右侧 4 位图形验证码（点击图片可刷新，验证码 2 分钟内有效、一次性使用）。
3. 点击「登录」，成功后进入数据总览页。
4. 侧边栏左下角显示当前用户与角色；点击「退出登录」结束会话并写入登出日志。

### 6.2 实时监控与违规告警

1. 进入「实时监控」页，选择本地视频文件或开启 PC 摄像头。
2. 页面按间隔抽帧后经 WebSocket 送检：YOLO 返回目标框与计数，千问 VL 返回违规结论与风险等级。
3. 检出违规时系统自动完成三件事：写入告警表、抓拍当前帧存证、向所有在线页面广播告警。
4. 任何页面在线时都会收到告警：右下角弹窗（含抓拍图与等级色，一般告警 5 秒自动消失，一级告警需手动关闭）+ 语音播报"注意，检测到 XX 违规"。
5. 页面顶部滚动告警条展示最近 10 条未处理告警，一级告警置顶；可通过「静音」开关关闭语音。

> 同一违规类型在「告警防抖时长」内只产生一条告警，避免刷屏。

### 6.3 告警查询与处理

1. 进入「告警管理」页，按时间范围、违规类型、告警等级、处理状态筛选，点击「查询」（「重置」清空条件）。
2. 列表展示时间、点位、违规类型、等级（红 / 橙 / 黄标签）、置信度、状态；点击「抓拍图」查看原始图片。
3. 对确认的隐患点击「处理」，填写整改备注后提交，状态变为「已处理」；误判的告警点击「驳回」标记为「已驳回」。
4. 处理与驳回操作会自动写入操作日志。

### 6.4 违规取证查看

1. 在告警详情中查看抓拍图，或通过取证接口按时间 / 点位 / 违规类型检索。
2. 点击下载取证图片，下载动作会记录操作人与时间，用于溯源。

### 6.5 设备管理（超级管理员）

1. 进入「设备管理」页，左侧为车间分组树，点击分组筛选右侧设备列表。
2. 「+ 新增设备」填写编号、名称、类型、车间、安装位置、IP、基准在线状态与 AI 开关；编辑 / 删除同理（删除有二次确认）。
3. 打开「心跳模拟上报」后，前台每 10 秒为基准在线设备上报心跳；关闭后 60 秒内设备自动转为离线（绿色圆点变红）。
4. 设备的增删改均写入操作日志。

### 6.6 数据总览与统计报表

1. 「数据总览」页顶部展示今日告警、待处理隐患、在线设备（含在线率）、今日一级告警四张卡片。
2. 图表区展示近 7 日违规类型占比、告警趋势折线、车间违规排名；下方为最新 10 条告警。
3. 「统计报表」页切换日报表 / 周报表 / 月报表维度，可按违规行为、处理状态过滤。
4. 点击「导出 CSV」下载当前筛选条件下的隐患台账（隐患编号形如 `HZ00001`），文件带 UTF-8 BOM，Excel 双击打开不乱码。

### 6.7 系统配置（超级管理员）

1. 进入「系统配置」页，可分别开关 YOLO 目标检测与千问大模型分析，并逐类启停五种违规识别（抽烟 / 未戴安全帽 / 打架斗殴 / 火灾 / 攀爬围墙）。
2. 拖动滑块调整 YOLO 置信度阈值（0.30 ~ 0.90），设置告警防抖时长（1 ~ 3600 秒）。
3. 点击「保存配置」后**立即生效，无需重启服务**：关闭某违规类型后该类画面不再告警，调高阈值后低置信度目标不再报出。
4. 每次配置变更都会记录变更前后的值到操作日志。

### 6.8 操作日志与溯源（超级管理员）

1. 进入「操作日志」页，按时间范围、操作用户、操作类型筛选，分页查看。
2. 已覆盖的操作类型：登录、登出、告警处理、误报驳回、证据下载、设备新增 / 修改 / 删除、配置修改。
3. 每条记录包含时间、操作用户、操作类型与详情（如"告警 HZ00015（火灾 / 未分配点位）：待处理 → 已处理；备注：…"）。

## 七、接口清单

### 7.1 页面与静态资源

| 接口 | 类型 | 说明 |
|---|---|---|
| `/` | HTTP GET | 返回 `index.html`；根目录整体作为静态站点挂载 |

### 7.2 AI 检测与实时推送

| 接口 | 类型 | 说明 |
|---|---|---|
| `/ws/detect` | WebSocket | 接收 `base64_image`，YOLOv8m 检测（car / truck / person），返回框坐标与置信度 |
| `/ws/qwen` | WebSocket | 接收 `base64_image`，千问 VL 分析，返回违规文本、违规项列表、风险等级；检出违规时自动入库、抓拍存证并广播告警 |
| `/ws/notify` | WebSocket | 单向告警广播通道，新告警产生时推送给所有在线前端 |
| `/detect` | HTTP POST | 兼容接口，请求体 `{"base64_image": "..."}`，返回 YOLO 检测结果 |

### 7.3 业务接口（`/api/*`，均需登录，响应统一为 `{status, ...}`）

| 接口 | 方法 | 说明 | 角色限制 |
|---|---|---|---|
| `/api/captcha` | GET | 获取图形验证码 | 匿名 |
| `/api/login` | POST | 登录，返回 token | 匿名 |
| `/api/logout` | POST | 登出 | 已登录 |
| `/api/me` | GET | 当前用户与角色 | 已登录 |
| `/api/alarms` | GET | 告警分页查询（时间 / 类型 / 等级 / 状态） | 已登录 |
| `/api/alarms/summary` | GET | 今日告警、待处理、各等级数量 | 已登录 |
| `/api/alarms/recent` | GET | 最新告警列表 | 已登录 |
| `/api/alarms/{id}` | PATCH | 处理 / 驳回告警 | 超管、安全管理员 |
| `/api/alarms/export` | GET | 导出 CSV 台账 | 超管、安全管理员 |
| `/api/evidences` | GET | 取证记录检索 | 超管、安全管理员 |
| `/api/evidences/{id}/image` | GET | 取证图片下载（记操作日志） | 超管、安全管理员 |
| `/api/stats` | GET | 总览统计数据（卡片 / 占比 / 趋势 / 排名 / 最新告警） | 已登录 |
| `/api/devices` | GET / POST | 设备列表 / 新增 | 仅超管 |
| `/api/devices/{id}` | PUT / DELETE | 设备修改 / 删除 | 仅超管 |
| `/api/devices/workshops` | GET | 车间分组及在线统计 | 仅超管 |
| `/api/devices/{id}/heartbeat` | POST | 心跳上报 | 仅超管 |
| `/api/config` | GET / PUT | 系统配置读取 / 修改 | 仅超管 |
| `/api/logs` | GET | 操作日志分页查询 | 仅超管 |
| `/api/logs/filters` | GET | 日志筛选项（用户 / 类型） | 仅超管 |

## 九、常见问题

| 现象 | 原因与处理 |
|---|---|
| 服务启动时报数据库连接失败 | 检查 MySQL 是否已启动、`.env` 中连接信息是否正确；若本机装了多个 MySQL 实例，确认占用 `3306` 端口的是项目所用的那一个 |
| 千问分析不生效、无新告警 | 未配置 `DASHSCOPE_API_KEY`，或「系统配置」中关闭了千问总开关 / 对应违规类型 |
| 页面图表空白 | ECharts 走 CDN 加载，需可访问外网；离线环境请把 `echarts.min.js` 下载到本地并修改页面引用 |
| 提示模型权重缺失 | 根目录缺少 `yolov8m.pt`，按「部署步骤 2」获取 |
| 设备一直显示离线 | 进入设备管理页打开「心跳模拟上报」，或检查设备基准在线状态是否为「在线」 |
| 车间违规排名多为「未分配点位」 | 告警点位需与设备安装位置一致才能归属车间；实时监控页尚未绑定设备点位，故默认归入未分配 |

## 十、说明与边界

- 本项目为培训练手项目，遵循"从简实现"原则：数据库只做「加列 / 加表」变更，不引入 ORM 与前端构建工具链。
- 不做真实摄像头 / 边缘盒子 / 声光报警器 / NVR 硬件对接，不做 100 路并发、断网续存与国产化适配；移动端仅做基础响应式适配。
- 时间统一使用本地时间，格式 `YYYY-MM-DD HH:MM:SS`。
- 用户输入渲染到页面统一经 `escapeHtml` 转义，防止 XSS。
